# R Data Analysis Internship – Week 1

## Titanic Dataset: Data Cleaning and Exploratory Data Analysis

### Project Overview
This project focuses on data cleaning, preprocessing, exploratory data analysis (EDA), and statistical analysis using R. The Titanic dataset is used to explore passenger demographics and survival patterns.

### Objectives
- Understand the dataset structure and variables.
- Identify and handle missing values.
- Detect duplicate records and outliers.
- Perform feature engineering.
- Generate descriptive statistics.
- Analyze correlations between numerical variables.
- Prepare a professional analysis report.

### Tools & Technologies

### Dataset Summary
- Original records: 891
- Original columns: 12
- Records after cleaning: 891
- Missing values after cleaning: 0
- Overall survival rate: 38.38%

### Key Findings
- Female survival rate: 74.20%.
- Male survival rate: 18.89%.
- First-class survival rate: 62.96%.
- Second-class survival rate: 47.28%.
- Third-class survival rate: 24.24%.
